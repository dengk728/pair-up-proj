One Project: A Flatpack Stool

This project is a flatpack stool I made for Models, Mockups, and Prototypes last semester. It is made with maple, glue, and paracord. This project disassembles and is able to fit into a Medium size fedex box (inside dimensions: 13.25" x 11.5" x 2.38"). It is able to raise a person 11 inches off the ground and can support my professor's weight (who is well over 6 feet tall)!
